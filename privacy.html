개인정보 안내

rclone-mac-backup은 선택한 로컬 파일을 본인의 Google Drive에 보관하는 본인용 Mac 백업 도구입니다.

설계상 요청 권한은 drive.file만이며, 앱이 만들거나 앱에서 열도록 선택한 파일에 한정합니다. Google OAuth로 연결하고 Google Drive가 파일을 처리·보관합니다.

토큰은 접근을 제한한 로컬 저장소에 보관하도록 설계합니다. 암호화 보관을 보장하지 않으며, 사용자가 Mac과 로컬 접근 권한을 관리해야 합니다.

개발자 서버로 파일이나 인증정보를 수집하지 않으며 판매하거나 광고에 이용하지 않습니다.

Google 계정에서 연결을 철회해도 이미 Google Drive에 저장한 파일이 자동 삭제되지는 않습니다. 파일 삭제는 사용자가 별도로 관리합니다.

이 안내페이지에는 자체 추적, 입력 폼, 외부 코드 또는 외부 글꼴이 없습니다. GitHub Pages의 접속기록 처리는 GitHub의 개인정보 정책이 적용됩니다.

Google Drive와 OAuth의 처리는 Google 개인정보처리방침을, 사이트 호스팅은 GitHub 개인정보처리방침을 참고하세요.
